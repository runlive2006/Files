## 0. 怎么运行

解压后直接双击 `Files.exe`。**普通用户即可运行，不需要管理员权限。**

若被 SmartScreen 拦截：点「更多信息」→「仍要运行」；或先双击包内的 `unblock.cmd`。
彻底解决需要代码签名证书（见 [DEPLOY.md](DEPLOY.md) §2）。

若想同时看性能数据：

```powershell
.\Files.exe --perf
```

**数据位置**：全部在 `Files.exe` 同级的 `data\` 下（`settings.json` / `logs\` / `temp\`）。
**重置配置**：删除 `data\` 目录后重启。整个文件夹可直接拷走，无其他残留。

## 1. 优先验证：标签页（本次新增）

| # | 操作 | 预期 |
| --- | --- | --- |
| 1.1 | 按 `Ctrl+T` 或点栏头「＋」 | 新建标签，路径与当前相同；标签条出现 |
| 1.2 | 只有 1 个标签时 | 标签条**隐藏**，不占垂直空间 |
| 1.3 | 在第二个标签里进入别的目录 | 两个标签各自独立；标签标题显示目录名 |
| 1.4 | **点另一个标签的标签名（不是 ✕）** | 切换成功，回到该标签原来的目录 |
| 1.5 | 切换标签后观察 | **滚动位置与选中项被恢复** |
| 1.6 | 按 `Ctrl+W` 或点标签上的 ✕ | 关闭当前标签；只剩 1 个时关闭被拒绝 |
| 1.7 | 按 `Ctrl+Tab` / `Ctrl+Shift+Tab` | 在标签间循环切换 |
| 1.8 | 关闭标签后按 `Ctrl+Shift+T` | 恢复最近关闭的标签 |
| 1.9 | 开两个指向同名目录（如 `A\src` 与 `B\src`）的标签 | 标题自动带上父目录：`A\src`、`B\src` |
| 1.10 | 四栏下每栏各开 2–3 个标签 | 各栏标签互不干扰；内存不持续增长 |
| 1.11 | 开多标签后关闭程序再打开 | 标签列表与活动标签都被恢复 |

> **重点**：1.5（滚动/选择恢复）与 1.10（多栏×多标签内存）是最容易出问题的地方。

## 2. 优先验证：多栏布局

| # | 操作 | 预期 |

| 2.3 | 按 `Ctrl+1` | 回到单栏，保留的是**当前焦点栏** |
| 2.4 | 拖动中间的分隔条 | 平滑缩放，两侧内容自适应 |

## 7. 已知限制（**不必报告**，已在计划中）

- 长路径（>260 字符）的文件操作会失败，M3 换 `IFileOperation` 后解决
- 复制大文件时**没有自定义进度对话框**，界面会显示「正在…」但无进度条；长操作不可取消
- 重命名是弹窗，不是列表内联编辑
- 图标是彩色方块占位，不是真实文件图标
- 没有标签页（下一步做）
- 没有搜索、没有右键第三方扩展菜单、没有预览窗格

## 8. 请重点反馈这四件事

1. **切换布局时目录是否被意外重置**（1.2 / 1.3）
2. **四栏的实际观感**：是否拥挤？地址栏、列头、状态栏在 1100×640 下是否够用？
3. **分隔条拖动手感**：是否跟手、有没有跳动
4. **启动速度**：双击到窗口出现，主观上多久？与资源管理器相比如何

如遇崩溃，请把 `data\logs\` 下的 `crash-*.log` 发给我（程序会主动写这个文件，并在弹窗里显示路径）。
