## 0. 怎么运行

解压后直接双击 `Files.exe`。**普通用户即可运行，不需要管理员权限。**

若被 SmartScreen 拦截：点「更多信息」→「仍要运行」；或先双击包内的 `unblock.cmd`。
彻底解决需要代码签名证书（见 [DEPLOY.md](DEPLOY.md) §2）。

若想同时看性能数据：

```powershell
.\Files.exe --perf
```

**数据位置**：全部在 `Files.exe` 同级的 `data\` 下（`settings.json` / `logs\` / `temp\`）。
**重置配置**：删除 `data\` 目录后重启。整个文件夹可直接拷走，无其他残留。

## 7. 已知限制（**不必报告**，已在计划中）

- **重名冲突与进度仍用系统自带对话框**：尚未做"聚合整批"的自定义对话框（PRD DLG-01/02 待做）
- **重命名是弹窗**，不是列表内联编辑
- **`.exe` / `.lnk` 显示通用图标**：系统图标按扩展名获取（零磁盘访问），
  精确到每个文件需要每项一次磁盘访问，与 10 万项性能目标冲突
- **没有分组视图**（按类型/大小/日期分组）
- **没有右键第三方 Shell 扩展菜单**
- 属性对话框调用的是**系统原生**对话框，本程序不提供自绘版本
- **没有回收站视图**（已决定不做）：删除到回收站功能正常，还原请用系统资源管理器
- **没有网络位置**（工作组/共享）
- **没有预览窗格**（优先级最低、待定）
- ~~搜索结果没有"路径"列~~ → **已修复**，搜索时列表会多出「路径」列
- **部分设置项尚不生效**：图标尺寸、交替行颜色、网格线、单实例、启动行为等
- **库（Libraries）已取消**，不会实现

> 完整的剩余任务与优先级见 [DEV-PLAN.md](DEV-PLAN.md) §2。
